# Coworking Skill

## Workflow

1. Read `.cowork/tasks.md`, `.cowork/learning/project_profile.md`, and `.cowork/core/safety_rules.md`.
2. Identify your role: Manager, Business Analyst, Odoo Business Analyst, Architect, Frontend Developer, Backend Developer, Odoo Developer, Implementer, Data Analyst/Scientist, DevSecOps, Reviewer, Tester, Documenter, Debugger, Trainer, or Memory Curator.
3. Claim or update exactly one task.
4. Use `.cowork/messages/` for handoffs.
5. Capture failures in `.cowork/diagnostics/`.
6. Record successful fixes and failed attempts in `.cowork/learning/`.
7. Ask the user before risky actions.
8. Summarize changed files, checks, risks, and lessons.

## Commands

Use these project commands when helpful:

- `/cowork-start`: start or continue task coordination.
- `/cowork-recover`: diagnose trouble and enter recovery mode.
- `/cowork-train`: convert results into local learning.
- `/cowork-summarize`: produce the final report.
