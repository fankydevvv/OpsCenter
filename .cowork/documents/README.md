# Project Documents

Store durable output documents here. Use subfolders for SRS, BRD, BRS, database design, technical design, requirements analysis, and business-system specific documents. Keep working notes in business memory; keep deliverable documents here.

## Folder map

- `srs/`: Software Requirements Specification outputs.
- `brd/`: Business Requirements Document outputs.
- `brs/`: Business Requirement Specification outputs.
- `database-design/`: database design, schema, ERD, TKCSD, migration design, table contracts.
- `technical-design/`: technical design, detailed design, TKCT, architecture decisions intended as deliverables.
- `requirements-analysis/`: phan tich yeu cau, requirement decomposition, stakeholder analysis.
- `business-systems/`: one subfolder per business system or module when documents span multiple systems.
